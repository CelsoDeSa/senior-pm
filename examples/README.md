# Examples

These inputs are repository-neutral. The generated sample is preserved separately from the reusable request and configuration examples.

- [Project-safe JSONC](config/project-safe.jsonc) — project-controlled restrictions and product policy
- [Operator autonomous JSONC](config/operator-autonomous.jsonc) — autonomous assumptions with sensitive capabilities disabled

Copy only the settings you need. Project config and plugin tuple options cannot enable operator-only capabilities. Restart OpenCode after changing configuration.
